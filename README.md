# Transfert QR

Transfert direct (WebRTC, chiffré) entre deux appareils, sans compte ni stockage.

- **Téléphone** : un ou plusieurs fichiers, un dossier ou un .zip, reçus en scannant un QR code.
- **PC à PC** : même chose avec un code à 6 caractères ou un lien.
- **Liens** : envoi d'un lien par QR code ou par code.

Plusieurs fichiers ou un dossier sont regroupés automatiquement dans une archive .zip (sans compression, limite 4 Go). Un .zip choisi seul est envoyé tel quel.
