# Transfert QR

Application web (PWA) pour envoyer et recevoir fichiers, dossiers et liens d'un appareil à l'autre.

Site : https://mathurin0501.github.io/Download/

Catégories : Téléphone, PC à PC, Liens, Hors ligne (QR codes animés, `sender.html` / `receiver.html`).

Le mode hors ligne vient du projet [multi-qr-air-gapped-file-transfer](https://github.com/glowinthedark/multi-qr-air-gapped-file-transfer) (GPL-2.0, voir `LICENSE`).
